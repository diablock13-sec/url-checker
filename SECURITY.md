# Kebijakan Keamanan

## Melaporkan kerentanan

Jangan buka issue publik untuk kerentanan. Gunakan fitur "Report a vulnerability" di tab Security repositori ini (GitHub private vulnerability reporting), atau kirim email ke diablock13@gmail.com.

Sertakan langkah untuk mereproduksi, versi yang terdampak, dan dampaknya. Ini proyek pribadi dengan perawatan seadanya, jadi tidak ada jaminan waktu respons.

## Cakupan

Hal yang relevan: kebocoran kunci API, penulisan file di luar `~/.cache/url-checker/`, dan penanganan input URL yang berbahaya.

Di luar cakupan: hasil penilaian yang keliru (AMAN untuk situs berbahaya, atau sebaliknya). Itu keterbatasan yang sudah dijelaskan di README. Laporkan lewat issue biasa.

## Catatan privasi

URL yang diperiksa dikirim ke VirusTotal. Lihat bagian Privasi di README.
